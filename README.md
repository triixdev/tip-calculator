# Tip Calculator

A simple, responsive tip calculator that splits the bill between people. Built with Cursor for the Global Hack Week challenge "Build a Mini App with Cursor".

**Live site:** https://triixdev.github.io/tip-calculator/

## Features
- Bill amount input with 10%, 15% and 20% tip buttons plus a custom tip field
- Splits the total between any number of people
- Shows tip amount, total and amount per person
- Dark/light mode toggle that remembers your choice
- Maroon and beige theme, responsive layout
- Handles empty and invalid input without errors

## Tech used
HTML, CSS, JavaScript, Cursor, GitHub Pages

## How I used Cursor
1. Described the app in one prompt and let Cursor scaffold `index.html`, `style.css` and `script.js`.
2. Tested it in the built-in browser and checked the numbers (500 bill, 15% tip, 2 people gives 75.00 tip, 575.00 total, 287.50 each).
3. Asked Cursor to add a dark mode toggle and a visible selected state for the tip buttons.
4. Asked it to restyle the app in a maroon and beige theme.

## Run locally
Open `index.html` in a browser.
